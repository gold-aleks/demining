# Структура проєкту «Розмінування України»

Цей файл пояснює, як організовані дані та JSON-файли в енциклопедії вибухонебезпечних предметів (ВНП).

## Загальна схема

```
mine guide/
├── index.html              # Головна сторінка — каталог карток
├── object.html             # Сторінка однієї картки об'єкта
├── glossary.html           # Словник скорочень
├── imas.html               # Довідник стандартів IMAS
├── css/                    # Стилі
├── js/                     # Логіка застосунку (завантаження, пошук, фільтри)
├── img/                    # Логотип та загальна графіка
├── data/
│   ├── index.json          # Маніфест: список усіх категорій
│   ├── abbreviations.json  # Скорочення для glossary.html
│   ├── imas/               # Індекс і витяги стандартів IMAS
│   │   ├── index.json
│   │   └── docs/           # Повні витяги (09.10.json …)
│   ├── indexes/            # Короткі індекси категорій (для каталогу)
│   ├── objects/            # Повні картки об'єктів
│   ├── photos/             # Фото для карток
│   └── icons/              # SVG-іконки
├── manifest.json           # PWA-маніфест
└── sw.js                   # Service Worker (офлайн-кеш)
```

**Як це працює:**

1. Застосунок читає `data/index.json` — дізнається, які є категорії.
2. Для кожної категорії завантажує файл з `data/indexes/` — отримує **короткий список** карток (назва, мініатюра, теги).
3. Коли користувач відкриває картку — завантажується **повний JSON** з `data/objects/{категорія}/{id}.json`.

## Категорії: теки ↔ назви

Кожна категорія має **три пов’язані імені**:

| Тека в `data/objects/` | ID у `data/index.json` | Назва українською |
| --- | --- | --- |
| `mines` | `mines` | Міни |
| `cluster` | `cluster` | Касетні боєприпаси |
| `artillery` | `artillery` | Артилерійські снаряди |
| `rockets` | `rockets` | Ракети РСЗВ |
| `missiles` | `missiles` | Ракети |
| `aerial-bombs` | `aerial-bombs` | Авіабомби |
| `grenades` | `grenades` | Гранати |
| `rpg` | `rpg` | Реактивні гранати |
| `mortar` | `mortar` | Мінометні міни |
| `fuzes` | `fuzes` | Підривники |
| `ied` | `ied` | IED |
| `uav` | `uav` | БПЛА |

Відповідність «назва категорії → тека» задана в `js/filters.js` (`CATEGORY_FOLDERS`).

**Приклад:** картка гранати РГД-5:
- індекс: `data/indexes/grenades.json`
- повна картка: `data/objects/grenades/RGD5.json`
- фото: `data/photos/rgd5.webp`

## `data/index.json` — головний маніфест

Короткий файл-«зміст» усього каталогу.

```json
{
  "version": "2.0",
  "updated": "2026-07-26",
  "title": "Розмінування України",
  "description": "Інтерактивна енциклопедія вибухонебезпечних предметів",
  "language": "uk",
  "categories": [
    {
      "id": "grenades",
      "name": "Гранати",
      "index": "data/indexes/grenades.json",
      "count": 0
    }
  ]
}
```

| Поле | Призначення |
| --- | --- |
| `id` | Технічний ідентифікатор категорії (латиницею, через дефіс) |
| `name` | Назва українською для інтерфейсу |
| `index` | Шлях до файлу індексу категорії |
| `count` | Орієнтовна кількість карток (довідково; каталог працює і без точного значення) |

**Після додавання нової категорії** потрібно записати її сюди та створити відповідний файл у `data/indexes/`.

## `data/indexes/*.json` — індекси категорій

Легкі списки для **каталогу, пошуку та фільтрів**. Не містять повного тексту картки.

```json
{
  "category": "Гранати",
  "folder": "grenades",
  "objects": [
    {
      "id": "RGD5",
      "name": "РГД-5",
      "family": "РГД",
      "category": "Гранати",
      "type": "Ручна уламкова наступальна граната",
      "thumbnail": "data/photos/rgd5.webp",
      "danger_level": "critical",
      "country": ["СРСР", "росія", "Україна"],
      "service_since": 1954,
      "updated": "2026-07-25",
      "tags": ["РГД-5", "RGD5", "граната"],
      "has_photos": true,
      "has_videos": false,
      "has_schemes": false
    }
  ]
}
```

### Обов’язкові поля запису в індексі

| Поле | Опис |
| --- | --- |
| `id` | Унікальний ID латиницею (без пробілів). Має збігатися з іменем JSON-файла: `{id}.json` |
| `name` | Назва для відображення (напр. «ТМ-62М», «МВП-62М») |
| `category` | Українська назва категорії (як у `category` файлу індексу) |
| `type` | Короткий тип об’єкта |
| `thumbnail` | Шлях до мініатюри в каталозі |
| `danger_level` | `low` · `medium` · `high` · `critical` |
| `tags` | Масив рядків для пошуку |

### Рекомендовані поля

| Поле | Опис |
| --- | --- |
| `family` | Сімейство / серія (ТМ-62, ПМН, FAB…) |
| `country` | Масив країн походження або застосування |
| `service_since` | Рік прийняття на озброєння |
| `updated` | Дата останнього оновлення картки (`YYYY-MM-DD`) |
| `has_photos` | `true`, якщо є фото в повній картці |
| `has_videos` | `true`, якщо є відео |
| `has_schemes` | `true`, якщо є схеми / креслення |

> **Примітка:** поле `"file": "data/json/..."` у старих записах — застаріле. Застосунок будує шлях сам: `data/objects/{folder}/{id}.json`.

## `data/objects/{категорія}/{id}.json` — повна картка

Детальна інформація про один об’єкт. Відображається на `object.html?id=RGD5`.

### Верхній рівень

```json
{
  "id": "RGD5",
  "classification": { ... },
  "identification": { ... },
  "technical": { ... },
  "explosive": { ... },
  "fuze": { ... },
  "deployment": { ... },
  "hazards": { ... },
  "recognition": { ... },
  "detection": { ... },
  "disposal": { ... },
  "medical": { ... },
  "history": { ... },
  "media": { ... },
  "references": [ ... ],
  "search": { ... },
  "version": "1.0",
  "updated": "2026-07-25"
}
```

### Секції картки

| Секція | Зміст |
| --- | --- |
| `classification` | Назва, категорія, тип, країна, рівень небезпеки, рік |
| `identification` | Опис, псевдоніми (`aliases`), призначення, попередження |
| `technical` | Розміри, маса, матеріал, колір, тип активації |
| `explosive` | Тип і маса вибухової речовини |
| `fuze` | Підривники, сумісність, протидія знешкодженню |
| `deployment` | Способи застосування, типові місця, конфлікти |
| `hazards` | Небезпеки, безпечні дистанції |
| `recognition` | Ознаки для візуального розпізнавання |
| `detection` | Міношукач, GPR, примітки |
| `disposal` | Рекомендації зі знешкодження, посилання на IMAS |
| `medical` | Ураження, перша допомога |
| `history` | Коротка історія, конфлікти |
| `media` | Фото, відео, схеми |
| `references` | Зовнішні джерела |
| `search` | `tags` і `synonyms` для пошуку |

### Секція `media`

```json
"media": {
  "photos": [
    {
      "src": "data/photos/rgd5.webp",
      "alt": "РГД-5",
      "type": "photo",
      "caption": "Ручна уламкова граната РГД-5"
    }
  ],
  "videos": [
    {
      "src": "https://youtu.be/...",
      "type": "video",
      "provider": "youtube",
      "caption": "Відео РГД-5"
    }
  ],
  "schemes": [],
  "xray": [],
  "drawings": []
}
```

Фото зберігаються в `data/photos/`. Підтримується формат `.webp`.

## `data/imas/` — довідник стандартів IMAS

Окремий довідник (як glossary), **не** категорія каталогу ВНП.

- `data/imas/index.json` — зміст: серії + короткий список документів
- `data/imas/docs/{id}.json` — стислий витяг стандарту (`08.10`, `09.11`, `09.30`…)
- Сторінка: `imas.html` (`js/imas.js`)
- З карток об’єктів коди в `disposal.imas` стають посиланнями на `imas.html?id=09.10`

Серії в індексі: **08** обстеження (NTS/TS), **09** очищення (clearance, BAC, будівлі, EOD, IEDD), **10** охорона праці.

```json
{
  "id": "09.11",
  "code": "IMAS 09.11",
  "title_uk": "Очищення району бойових дій (BAC)",
  "series": "09",
  "summary": "…",
  "key_points": ["…"],
  "official_url": "https://www.mineactionstandards.org/standards/09-11/",
  "related": ["08.10", "09.10", "09.30"],
  "related_glossary": ["bac", "erw", "eod"]
}
```

| Поле | Опис |
| --- | --- |
| `id` | Код без префікса (`09.10`) — збігається з іменем файла |
| `code` | Повний код для UI (`IMAS 09.10`) |
| `series` | Серія (`09`, `10`…) для фільтрів |
| `summary` / `key_points` | Стислий освітній витяг українською |
| `official_url` | Посилання на офіційний текст IMAS |
| `related` | Інші id документів у цьому довіднику |

> Витяги **не замінюють** офіційний IMAS / NMAS / SOP. Для нових стандартів: додати запис у `index.json` і файл у `docs/`.

## `data/abbreviations.json` — словник скорочень

Використовується на сторінці `glossary.html`. Окремий від карток об’єктів.

```json
{
  "items": [
    {
      "id": "mvp62m",
      "abbr": "МВП-62М",
      "full_uk": "Мінний підривник з пневматичним далеким зведенням МВП-62М",
      "category": "fuzes",
      "level": "advanced",
      "related": ["TM62P", "MVP62M"],
      "notes": "Коротке пояснення",
      "tags": ["MVP-62M", "підривник"]
    }
  ]
}
```

| Поле | Опис |
| --- | --- |
| `abbr` | Скорочення (ПМН, IMAS, МВП-62М…) |
| `full_uk` | Розшифровка українською |
| `full_en` | Необов’язково — англійською |
| `full_ru_note` | Необов’язково — російською (довідково) |
| `category` | Група: `mines`, `fuzes`, `standards`… |
| `related` | ID карток у каталозі, на які можна перейти |
| `level` | `basic` · `intermediate` · `advanced` |

## Як додати нову картку (чеклист)

1. **Обрати категорію** — наприклад, `fuzes` (Підривники).
2. **Додати фото** у `data/photos/` (якщо є).
3. **Створити повну картку** — `data/objects/fuzes/MVP62M.json`.
4. **Додати короткий запис** у `data/indexes/fuzes.json` → масив `objects`.
5. **Оновити `count`** у `data/index.json` для цієї категорії (за бажанням).
6. **За потреби** — додати скорочення в `data/abbreviations.json`.
7. Перевірити в браузері: каталог → картка → пошук за тегами.

### Правила іменування

- **ID** — латиниця, без пробілів і спецсимволів: `TM62M`, `MVP62M`, `FAB100`.
- **Ім’я файла** = `{id}.json`.
- **`id` у JSON** має збігатися з іменем файла та записом в індексі.
- **`category`** в індексі та в `classification.category` — українською, як у таблиці вище.

## Типові помилки

| Проблема | Рішення |
| --- | --- |
| Картка не з’являється в каталозі | Перевірити запис у `data/indexes/{категорія}.json` |
| «Картку не знайдено» | Перевірити шлях `data/objects/{folder}/{id}.json` і збіг `id` |
| Немає мініатюри | Заповнити `thumbnail` в індексі та `media.photos` у картці |
| Пошук не знаходить | Додати варіанти написання в `tags` і `search.synonyms` |
| Неправильна категорія | `category` в індексі має відповідати `CATEGORY_FOLDERS` у `filters.js` |
